# 04 · 运维（浏览器/进程/权限/备份）与故障速查

## 1. 浏览器：自己拉起 + CDP（**不要用 headless**）

真实故障：`playwright.chromium.launch(channel="msedge")` 连续 3 次 180 s 超时，失败会残留进程
（峰值 10 个），吃 CPU/内存/磁盘 IO → 整台机器其它程序打不开，甚至黑屏。

```bash
python scripts/edge_cdp.py start --port 9223     # 自己拉起最小化、低优先级的浏览器
browser = pw.chromium.connect_over_cdp("http://127.0.0.1:9223")   # Python 只负责连
python scripts/edge_cdp.py stop --port 9223      # 连子进程一起杀
```
- 一次会话做完全部事情（实测 + 门禁 + 导出 PDF + 预览图）；同一实例可连跑第二份墙报
  （每轮新开标签页，并留一张空白页防止浏览器自退）。
- Windows 用 `DETACHED_PROCESS | BELOW_NORMAL_PRIORITY_CLASS` 启动，桌面不卡。
- 独立 `--user-data-dir`（`_work/edgeprofile/`），不污染用户配置。
- 关闭只杀**自己启动的那棵树**（`taskkill /PID <pid> /T /F` 或进程组信号），
  不要 `killall msedge/chrome`；收尾残留必须为 0（crashpad 辅助进程会自退，不计入）。

## 2. LibreOffice（PPTX→PDF）与文件占用

`<node> "<kit>/lib/cli.js" convert --input x.pptx --output y.pdf` —— 用运行环境自带的 kit，
不要找系统 `soffice`；转换后的 PDF 页尺寸就是幻灯片尺寸（±1 mm 可校验）。
Windows 上用户开着 `poster.pptx` 时写入会 `PermissionError`：先重试（多为杀软/索引瞬时占用），
仍失败就**请用户关闭并提醒"关闭时不要保存"**；交付后让他"重新打开"。

## 3. 备份与权限

```
_backup/<yyyyMMdd_HHmm>_<label>/   html|pdf|pptx 全量副本（每轮改动前后各一次）
_work/shapes.json                  当前 PPTX 所依据的实测数据
_work/pretrim/                     裁白边前的原始素材
_work/edgeprofile/                 浏览器独立配置目录（可随时删）
```
- **每轮改动前先快照**（`50_snapshot.py`）→ 任何一版都可回退；用户明确要求保留历史备份。
- 跨目录写被拒时不要反复重试，改用工作区内副本；沙箱下 Node 的 `child_process` 默认管道捕获
  可能 `EPERM`（改 `stdio:'inherit'` 或由 PowerShell 调 CLI）；只读模式下 PowerShell 是
  ConstrainedLanguage，`.NET` 静态调用会失败。
- 中文控制台输出：`$env:PYTHONIOENCODING = "utf-8"`。

## 4. 交付前自检（30 秒）

`edge_cdp.py status` 残留 0 → `_backup/` 有本轮快照 → `40_verify_pptx.py` 五项全过 →
PDF 单页且尺寸正确 → 提醒用户"重新打开 PPTX"。

改过脚本或换过机器，再补一条：`python scripts/60_pressure_matrix.py --quick`（3 个中性样本，
约 1 分钟）——它专门验证"该过的能过、该拦的能拦住、不许 traceback"（见 `@references/07-pressure-matrix.md`）。

## 5. 故障速查（症状 → 根因 → 修法）

| # | 用户看到的 | 根因 | 修法 |
|---|---|---|---|
| 1 | 小结文字**压在左侧色条上**、整体偏上 | 文本盒取了边框盒，没算 padding/border | 规则 2（内容盒） |
| 2 | 项目符号与首字**重叠** | `li` 的 `padding-left` 没算 | 规则 2 + 10 |
| 3 | 编号方块的**数字是空的** | `.num` 不在文本选择器里 | 规则 7（`hv`） |
| 4 | 编号数字**整体偏右 3 px** | 所有文本框统一 +6 px，居中文本中心右移 | 规则 6（居中 ±24） |
| 5 | 编号 `[1]` **独占一行**、与下方 note 重叠 | flex 子元素被粘成一段 | 规则 8 |
| 6 | 小节标题**多出一行**，压住英文副标题 | 中文+英文是两段不同字号，行距按大字号算 | 规则 3（按段拆） |
| 7 | 图注**压在图片上** | 多行段落用"整块并集高"做垂直修正 → 整体下移 | 规则 3（首行字体盒高） |
| 8 | 标题块里**英文副标题压住作者行** | 同上（h1 内两段不同字号） | 规则 3 + 5 |
| 9 | 编号方块被渲染成**正圆** | `adj` 用 `radius/(min/2)` | 规则 9 |
| 10 | 断行位置与 PDF 不一致 | PPT 用 Arial，浏览器用中文字体（字宽不同） | 规则 11（latin/ea/cs 同族） |
| 11 | 指标卡文字**重叠/多折一行** | 居中文案没有宽度余量 | 规则 6 |

| 15 | **横幅被压扁/拉长**（圆变椭圆、字变宽） | `add_picture` 只按框拉伸，没有实现 `object-fit:cover` 的裁切 | 规则 12（写 `srcRect`） |
| 16 | 图片的**圆角变直角** | CSS `border-radius` 在 PPT 里没做 | 规则 12（`prstGeom roundRect`） |
| 17 | 交出的 PPTX **缺了好几张图**（可能是静默的） | 图片路径不对，`20_html2pptx.py` 只打印警告 | 第 4 步**退出码 1 且不写文件**；修路径或显式 `--allow-missing-images` |
| 18 | 某栏目**留白太多** | `flex:1 1 auto` 把余量平均分给该栏所有面板 | 放大该栏图片 / 补实质文字（每行 ≈27–35 px） |
| 19 | 某栏目**溢出/文字被裁** | 该栏内容总和 > 栏高 | 缩该栏图片宽度（等比）或删 1–2 行文字 |
| 20 | **右栏比页头缩进一条**（约 48 px） | `Σ栏宽+Σ间距` < 内容区宽，余量全落在右边 | 门禁第 5 项：按栏宽反推页边距 |
| 21 | 整版被**放大 1.25× 并裁掉右下** | 某些 PPT→PNG 工具对大幅面幻灯片会放大裁切 | 改用 `PPTX→(LibreOffice)PDF→pymupdf 位图` 校验 |

| 41 | 报"图片变形 2.86%"但图看着正常 | 旋转过的图：`getBoundingClientRect()` 给的是**旋转后包围盒** | 带 transform 的图不参与纵横比判定（用未变换尺寸绘制） |

| 43 | 换了自己类名的模板后"门禁全过"（其实什么都没测到） | 选择器 0 命中时旧版只打印提示 | SKILL 硬规则 14：0 命中判 FAIL；用 `--panel/--column/--poster` 覆盖选择器 |
| 44 | 浏览器里看不见的文字在 PPT 里**实心出现** | `opacity:0` 的 0 被当成真值（`parseFloat("0")` 明明返回 0） | 采集阶段就把 opacity≈0 的内容当不可见 |
| 45 | 某行文字在 PPT 里**整行消失**（文字全在 `<span>` 里） | 兜底扫描只认"直接文本子节点" | 行内子元素里的文字也要收；不可见的要显式跳过 |
| 46 | 验收报"编号居中 OK"，其实一个编号都没测到 | `ok` 只在"有数据"的分支里被赋值 | SKILL 硬规则 14：没有可比对的编号 = FAIL（`--no-badge-check` 显式放行） |
| 47 | 缺图/坏图/SVG 直接抛 traceback 或静默少图 | 未区分"本地相对路径 / data: / http(s): / file:"，也未逐图容错 | 逐图 try/except + 明确报"不能内嵌"；缺图 → 退出码 1 且不产出文件 |
| 48 | 一致性校验报 `UnicodeEncodeError: 'gbk' ... '−'`（看着像版式失败） | Windows 中文控制台默认 GBK，脚本打印 `−/≈` 就崩 | 每个脚本把 `stdout/stderr` 重设为 UTF-8（`errors="replace"`）；调试时也可先 `set PYTHONIOENCODING=utf-8` |

## 6. 内容层面的经验（同样会"错版"）

- 每节末尾的 note 只讲本节图；跨节指代必须显式写图号（"见 Fig. N（panel M）"）。
- 合并图后图号不要重排（用"一图两图注"），否则正文里所有 `Fig. N` 都要跟着改。
- 引用风格统一（作者. 题目. *刊名* **年**, *卷*, 页码. DOI）；**不要把别人文献里的数据当自己的论据**。
- 每个数字都要能在图或文献里找到出处；图注与**图内标注**不一致时以图为准，并请用户确认。
- 举例要精确到"找什么、改什么、看什么"，不要把常规条件写成唯一边界（"只能这样"通常是错的）。
- 提到表征/检测手段时，手段必须与它真能回答的问题匹配（尺度、灵敏度、能看界面还是只能看表面）：
  写之前先确认"这个手段能不能看到我要说的现象"，否则是硬伤。
- 交付前把用户的**会议编号框**放回右下角（保留模板样式），并保留底部边距。
- 用别人的图/logo 要留痕：见 `@references/00-install.md` 第 6 节（图片版权与合规）。
- 多轮返工时的接反馈方式、文案纪律与交付清单见 `@references/06-field-notes.md`。
